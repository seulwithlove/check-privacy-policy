# 개인정보처리방침 

**한국어** | [English](README.en.md)

**당신의 데이터는 소중합니다. 동의하기 전에 무엇에 동의하는지 알아야 합니다.**

대부분의 서비스는 개인정보를 어떻게 다루는지 명확히 알려주지 않고, 개인정보처리방침은 너무 길어서 아무도 읽지 않습니다. 이 오픈소스 크롬 확장 프로그램은 방침을 대신 읽고, 내 데이터를 위험하게 만드는 조항을 찾아 알려줍니다. 원문을 그대로 인용하므로 직접 확인할 수 있습니다.

## 현재 상태
1단계(MVP): 방침 URL을 붙여넣거나 현재 페이지에서 자동으로 찾으면 위험 점수와 원문 인용이 포함된 경고 항목을 보여줍니다. 본인의 Anthropic 또는 OpenAI API 키를 직접 사용하며, 키는 브라우저 안에만 저장됩니다.

## 개발
```
npm install
npm run build      # 이후 chrome://extensions → 압축해제된 확장 프로그램을 로드 → dist/ 선택
npm test
```

평가 규칙은 `rubric/core.json`에 있으며, 규칙 개선 기여를 환영합니다. 자동 분석은 틀릴 수 있으며 법률 자문이 아닙니다.

## 개인정보 보호
- 텔레메트리, 분석 도구, 계정이 없으며 별도 서버도 없습니다.
- API 키는 브라우저의 `chrome.storage.local`에만 저장되고, 선택한 제공자에게만 전송됩니다.
- 분석을 위해 개인정보처리방침 본문만 해당 제공자에게 전송됩니다. 분석 결과(키 제외)는 최대 50건까지 로컬에 캐시됩니다.
- 결과는 자동 분석이며 법률 자문이 아닙니다.
